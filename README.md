# Extreme Winter · 极寒生存 26.0.7

Minecraft Java **26.1.2 / Fabric / 单人**的新手慢节奏寒潮生存。开局先搭顶、放营火，再安排外出。

## 安装与开始

1. 使用 Minecraft 26.1.2、Fabric Loader 0.19.5、Fabric API 0.155.3+26.1.2、Java 25+。
2. 将 `outputs/extreme-winter-26.0.7.jar` 安装到独立实例；只保留一份本模组。不安装 sources 或 gametest JAR。
3. 新存档额外领取 1 营火、16 火把、1 石铲、4 烤马铃薯和生存手册。新老玩家以独立收据只领一次手册；升级、死亡、重登不重复发物资。
4. 饱食度上方十枚火焰表示 **温暖度**（0—100），箭头表示趋势；⌂ 为庇护，+ 为有效热源。不是摄氏温度。

本轮仅在项目和独立测试实例开发，未安装到用户真实游戏实例，未发布或推送。旧版本成品和 MVP 标签保留。

## 当前已实现的新手规则

- 累计实际运行 0—60 / 60—120 / 120—180 / 180—270 / 270+ 分钟，对应准备、初霜、降温、深冬、长冬；失温倍率 .65 / .8 / 1 / 1.1 / 1.25。跨维度共享时钟，睡觉和 `/time` 不跳级，暂停/离线不补算。
- 准备期主世界温暖度最低 70。新生/死亡重生另有 180 秒本模组冻伤保护，重登不刷新。
- 低于 25 累计 60 秒预警后才可冻伤；回到 27 清除这次累计。每 10 秒 .5—1 点，最多降到 **6 点生命（三颗心）**。更低生命不受本模组冻伤，也不会被补血；其他原版危险正常，粉雪冻伤保留并与本模组间隔 5 秒。
- 缓慢 I 从低于 25 开始。本模组挖掘疲劳默认关闭，不移除其他来源的效果。
- 常态倍率 1、干燥雪中无装备无热源，100→25 白天约 22 分 44 秒、夜间约 19 分 14 秒；屋内 40→70 约 100 秒。这些是固定条件公式值。
- 庇护沿用中心有顶且周围 3×3 至少 7/9 列有顶；玻璃、完整树冠、洞顶有效。热源半径 4，墙体遮挡、距离衰减，多源叠加上限 4；火把强度 .35。
- 营火/灵魂营火露天耐候 10/15 分钟。火把掉落、炉具受冷停工、额外岩浆冷却分别默认关闭；旧 BLOCKED 炉具自动解锁，旧过冷火把可放置。
- 蹲下空手右键回收营火，保留耐候状态，烹饪食材安全掉落；营火物品背包约 30 秒恢复。耐候条不是燃料条。
- 新配置额外积雪上限 16 层（两格），间隔 80 tick；结冰间隔 200 tick。显式 `maxSnowLayers=0` 的旧配置仍保留无限模式；目标配置明确为 16。旧厚雪保留，手动堆放和重力合并仍守恒。
- 雪保留重力、下陷、正常跳跃、铲雪掉落；树冠下约四分之一采样；屋顶、作物、机器和含水方块保护保持。
- 静态冷群系仍为 -0.5；`coldModdedBiomes` 可选兼容 Terralith，保留用户实际开关。当前没有动态暖季，额外雪冰开关不禁止原版雪冰。

## 天气与外出窗口

默认 `weatherMode=scheduled`：缓和和普通降雪按保存的种子，以 10—20 分钟窗口交替。累计 85 分钟预警、90 分钟首次短暴雪（3 分钟），退潮 2 分钟后恢复缓和窗口。以后每次暴雪结束后 45—75 分钟再来一次，持续 5—7 分钟；每次仍预警 5 分钟、退潮 2 分钟。世界运行时钟和排期保存，睡觉、时间命令与重登不跳级或重抽。

准备期的降雪窗口以 25% 频率执行额外积雪，关闭额外结冰；普通降雪 100%，暴雪 200%，缓和期停止额外新增。每批候选预算、已加载边界和 16 层上限不变。**这些是本模组额外采样规则；原版雪冰和世界生成仍可能发生，已有雪不会在缓和期融化。**

暴雪只将露天空气失温额外乘 1.5，不额外放大浸水或室内损耗/恢复。HUD 独立显示天气、警报/事件倒计时；服务器切换时立即同步，平时每 10 秒校准。限定每 5 tick 最多 4 个偏斜原版雪粒子；风声使用原版资源及天气音量，屋顶下变弱。轻白雾和淡霜边使用独立原创GUI效果，不改变三维雾或Iris；`blizzardParticles` / `blizzardWind` / `blizzardHaze` / `blizzardFrost` 可以分别关闭，服务器危险程度不变。

统一控制器是唯一天气写入入口。旧 `persistentWeather` 字段保留，仅 `weatherMode=legacy` 时恢复旧持续降水；`vanilla` 完全交给原版。迁移时旧的 persistentWeather=false 默认选择 vanilla，保留用户原有禁用意图。

## 保暖与远征

- **羊毛内衬**：2 羊毛＋1 线；护甲＋内衬缝入一次。头/胸/腿/脚权重 15/40/30/15%，皮革加权减空气失温 15%，内衬 35%，完整带衬皮革减 50%。浸水损耗照常。附魔、耐久、名称、染色、饰纹及其他组件保留；工作台/铁砧修理和下界合金升级保留内衬。
- **热水袋**：3 皮革＋1 铁锭；对水源或装水炼药锅使用。手持在燃烧营火或取暖炉 2 格内无遮挡连续 10 秒充满，离开、收起或重登会重置这次充热。满热 12 个运行分钟，背包每秒补热 .03，多个不叠加。存箱和掉落保留同一到期时间；暂停、离线停钟。
- **暖身炖菜**：碗＋烤马铃薯＋熟牛肉或熟猪肉＋胡萝卜，16 个堆叠；恢复 6 饥饿值、4.8 饱和度、10 温暖度。5 分钟内空气失温再乘 .8，与内衬相乘。遵循普通进食限制，返还碗，重复食用刷新效果。
- **手册**：书＋羊毛，原版书籍阅读界面六页。2 铜锭＋玻璃＋红石合成温暖计；右键读取自身温暖度、寒潮阶段、庇护和有效热源。温暖计＋2 铜锭＋2 红石＋4 木板合成气象仪，放置右键读取服务器排期。
- 村庄五类屋内箱、废弃矿井、沉船三类箱的原版内置表追加补给；每箱约 1/3 概率抽一类。煤/木炭 2—6 权重 5、内衬 1 权重 3、空袋 1 权重 1、炖菜 1—2 权重 1。外部数据包替换表不追加，已打开箱不刷新，`structureSupplies=false` 可关闭。

## 生产与冬日家园

取暖炉用熔炉＋4 铁锭＋4 圆石合成；单燃料槽，自动接续燃烧，接受漏斗输入。原木 80 秒、木板 20 秒、木棍 10 秒、煤/木炭 8 分钟、煤块 72 分钟。燃烧时半径 6 格、源强度 1.25，距离衰减、墙体遮挡；可给热水袋充热。生存拆除返还未使用燃料，炉具物品保存当前燃烧进度；暂停、离线及区块卸载不补烧。

小麦、胡萝卜、马铃薯、甜菜、南瓜梗、西瓜梗、甜浆果在深冬随机生长减半、长冬减至四分之一；骨粉仍遵循原版规则。有顶、光照至少 9、作物位置有效农业热量至少 .25 时恢复原速。营火、燃烧熔炉和取暖炉有效，火把只照明，岩浆不提供农业热量；树苗及其他维度不受此门控。

原版进度界面记录搭顶、回温、制作内衬、充满热水袋、经历暴雪结束和温室收获。进入长冬，自己的炉具曾燃烧，温室累计收获 32 份作物且经历过暴雪，即可完成冬日家园。进度没有期限；打开界面和预览合成不会完成任务。砍树烧木炭、供暖种植、烤马铃薯制作炖菜、带热水袋远征并补回燃料，可形成持续的生产循环。

A—E已完成。34单元、五组每组19真实入口、两组Terralith/Eclipse、真实旧存档与原版危险/传送门扩展均通过；固定小场景CPU p95≤.42ms、额外视觉FPS下降7.75%。真实时间只做分段边界观测；完整证据及已知范围见 `outputs/beginner-26.0.7-validation.md`、`outputs/beginner-26.0.7-performance.md`。

沿用已安装 JDK 26、Gradle 9.8.0、Loom 1.18.2，输出 Java 25 字节码。不升级依赖。

```powershell
.\scripts\Build.ps1 -Tasks @('build','compileGametestJava')
.\scripts\Build.ps1 -Tasks @('runClientGameTest')
python tools/audit_package.py
.\scripts\Test-Matrix.ps1 -Profiles A,B,C,D,E
```
